# Ruchita Rani — Interior Architecture Portfolio

Interior Architecture & Design portfolio featuring selected academic, competition, and exhibition work (2024–2026).

## Tech Stack
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Smooth Scrolling:** [Lenis](https://lenis.darkroom.engineering/)
- **Interactive Components:** Physics-driven Lanyard Badge, 3D Glass Folders, Card-stack scroll animation

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, yarn, or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview
```bash
npm run preview
```

## Deployment
This project is configured for seamless zero-config deployment on [Vercel](https://vercel.com).
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
